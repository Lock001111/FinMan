Arti Warna Status Sinkronisasi

Hijau - Tersinkronisasi Seluruh data lokal di perangkat ini sama persis dengan data di Google Drive.
Kuning - Menunggu Sinkronisasi Ada perubahan lokal baru. Sistem menghitung jeda 60 detik sebelum otomatis mengunggah.
Biru - Sedang Memproses Sedang mengenkripsi data lokal atau mentransfer berkas ke/dari Google Drive.
Ungu - Data Baru Ditemukan Perangkat lain telah memperbarui data di Cloud. Data terbaru berhasil dimuat otomatis.
Merah - Perlu Perhatian / Konflik Sesi Google berakhir atau terjadi perbedaan versi data antara dua perangkat.

Terdeteksi Konflik Data Cloud!

Data di Cloud telah diubah perangkat lain, sementara perangkat ini juga memiliki perubahan baru.
